Prepara un handoff operativo in italiano, massimo 220 parole.

Includi solo:

- Branch corrente e stato git sintetico.
- Obiettivo della sessione.
- File modificati o creati, raggruppati per area.
- Verifiche eseguite e risultato.
- Rischi residui o cose non fatte.
- Prossimo passo consigliato.

Non includere log lunghi, diff completi, complimenti o narrativa.
