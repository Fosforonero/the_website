# Solar System Full Catalog Architecture — Sprint 03

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the Solar System Lab from a 27-body curated orrery into a progressive catalog browser covering all known Solar System object categories, using JPL SBDB for bulk small bodies, Horizons for precision on-demand vectors, and Three.js `Points`/`InstancedMesh` for scalable rendering.

**Architecture:** Static pre-generated catalog snapshots (JSON chunks per category, committed to `public/`) power the initial CatalogLayer; a Next.js API proxy enables live SBDB search and on-demand Horizons vectors. The Three.js scene gains a `CatalogLayer` component that renders up to tens of thousands of objects as Points with no individual React mesh per body. CelesTrak/SGP4 artificial satellites are explicitly deferred to Sprint 04.

**Tech Stack:** Next.js App Router, TypeScript, React Three Fiber, Three.js, JPL SBDB Query API, JPL Horizons API, tsx scripts (Node.js fetch), existing Keplerian solver from Sprint 02.

## Architecture Decisions

### 1. Static snapshots + live search hybrid

Pre-generated static JSON files (`public/lab/solar-system/catalog/`) power the initial CatalogLayer load. Each file is a compact chunk per category generated by a fetch script run at build/update time. Live SBDB search goes through a Next.js API route with `next/cache` revalidation.

Rationale: static snapshots give instant first load, no API rate limits on page render, and a known dataset with stamped retrieval date. Live search is for user-initiated queries.

### 2. Catalog JSON format (compact)

Each snapshot file uses array-of-arrays to minimise payload:

```json
{
  "meta": {
    "source": "JPL SBDB Query API",
    "url": "https://ssd-api.jpl.nasa.gov/sbdb_query.api",
    "retrievedAt": "2026-05-31",
    "category": "MBA",
    "count": 5000,
    "fields": ["id", "name", "a", "e", "i", "om", "w", "ma", "per", "d", "H", "class", "neo", "pha"]
  },
  "data": [
    ["2000001", "1 Ceres", 2.766, 0.076, 10.59, 80.33, 73.60, 77.37, 1681.6, 939.4, 3.4, "MBA", false, false]
  ]
}
```

Field order matches `meta.fields`. Nullable fields use `null`. Decoder in `lib/solar-system/catalog.ts` converts to `CatalogEntry[]`.

### 3. CatalogLayer — Three.js Points

A single `Points` object per active category, never individual React mesh components. Positions computed client-side from orbital elements using the Sprint 02 Keplerian solver. The layer re-computes when epoch changes only for visible/active categories (lazy).

```
CatalogLayer
  ├── useEffect: decode snapshot JSON → CatalogEntry[]
  ├── useMemo(epoch, distanceMode): compute [x,y,z] for each entry → Float32Array
  └── <points>
        <bufferGeometry>
          <bufferAttribute name="position" array={positions} />
          <bufferAttribute name="color" array={colors} />
        </bufferGeometry>
        <pointsMaterial vertexColors sizeAttenuation size={0.03} />
      </points>
```

Maximum ~50 000 points per layer is safe on modern GPU with Points.

### 4. Horizons on-demand vectors (per selected body)

When the user selects a catalog body (not a curated MVP body), the inspector fires a request to `/api/solar/horizons?id=<spkid>&date=<iso>`. The server fetches from JPL Horizons, parses the Cartesian vector, caches the result for 1 hour (Next.js fetch `revalidate: 3600`), and returns `{ positionKm, velocityKmS, epochIso, source: "jpl-horizons" }`.

The scene uses this vector to place a highlighted body sphere at the precise position. For MVP curated bodies, the existing Keplerian solver remains the source (Horizons upgrade is per-user-request only).

### 5. Search

`GET /api/solar/catalog/search?q=<term>&limit=20&category=all` proxies to SBDB and returns up to 20 matching objects with name, id, category, and orbital elements. The client shows an autocomplete dropdown. Selecting a result adds the body to the scene as a highlighted point and opens the inspector.

### 6. New body categories

`SolarBodyCategory` in `bodies.ts` gains `"centaur"` and `"spacecraft"`. `CatalogEntry` uses a superset type `CatalogCategory` that extends `SolarBodyCategory`.

### 7. Data quality disclosure

Every `CatalogEntry` and every MVP `SolarBody` state must carry:

```ts
type DataQuality = {
  source: "jpl-sbdb-static" | "jpl-sbdb-live" | "jpl-horizons-cached" | "mvp-keplerian";
  retrievedAt: string; // ISO date
  positionAccuracy: "sub-km" | "km-range" | "educational-keplerian" | "unknown";
};
```

The inspector panel shows this for all selected bodies, curated or catalog.

```ts
/**
 * Catalog data model for SBDB-sourced Solar System objects.
 *
 * These objects are NOT in the curated `SOLAR_BODIES` array.
 * They are loaded progressively as Points layers, not individual meshes.
 */

export type CatalogCategory =
  | "asteroid-neo"     // Near-Earth Objects
  | "asteroid-mba"     // Main Belt Asteroids
  | "asteroid-other"   // Other asteroid classes
  | "comet"
  | "tno"
  | "centaur";

export type CatalogMeta = {
  source: "JPL SBDB Query API";
  url: string;
  retrievedAt: string;         // ISO date string, e.g. "2026-05-31"
  category: CatalogCategory;
  count: number;
  fields: string[];
};

/**
 * Compact representation of a single small-body catalog entry.
 * Orbital elements are approximate (from SBDB, not live Horizons).
 */
export type CatalogEntry = {
  id: string;                  // SPK-ID from SBDB
  name: string;
  category: CatalogCategory;
  semiMajorAxisAu: number;     // a
  eccentricity: number;        // e
  inclinationDeg: number;      // i
  longitudeAscNodeDeg: number; // om (Ω)
  argPeriapsisDeg: number;     // w (ω)
  meanAnomalyDeg: number;      // ma (M at epoch)
  epochJd: number;             // tp converted to JD, or SBDB epoch_mjd+2400000.5
  periodDays: number;          // per
  diameterKm: number | null;   // d — null if unknown
  absoluteMagnitude: number | null; // H — null if unavailable
  isNEO: boolean;
  isPHA: boolean;              // Potentially Hazardous Asteroid
};

export type CatalogChunk = {
  meta: CatalogMeta;
  entries: CatalogEntry[];
};

// ---------------------------------------------------------------------------
// Raw SBDB field indices (must match meta.fields order in the JSON file)
// ---------------------------------------------------------------------------

const FIELD_ORDER = [
  "id", "name", "a", "e", "i", "om", "w", "ma", "epoch_mjd",
  "per", "d", "H", "class", "neo", "pha",
] as const;

type RawRow = [
  string,       // id
  string,       // name
  number,       // a
  number,       // e
  number,       // i
  number,       // om
  number,       // w
  number,       // ma
  number,       // epoch_mjd (Modified Julian Day)
  number,       // per (days)
  number | null, // d (km)
  number | null, // H
  string,       // class
  boolean,      // neo
  boolean,      // pha
];

function sbdbClassToCategory(cls: string, neo: boolean): CatalogCategory {
  if (neo) return "asteroid-neo";
  if (cls.startsWith("MB") || cls === "MBA") return "asteroid-mba";
  if (cls === "TNO" || cls === "KBO" || cls.startsWith("SDO") || cls === "DO" || cls === "DET") return "tno";
  if (cls === "Cen") return "centaur";
  if (cls.startsWith("HYP") || cls.startsWith("PAR") || cls.startsWith("COM") || cls === "JFC" || cls === "HTC" || cls === "ETc" || cls === "OCC") return "comet";
  return "asteroid-other";
}

/**
 * Decode a raw SBDB JSON chunk (array-of-arrays format) into typed CatalogEntry[].
 * Use this on the client after fetching the static JSON snapshot.
 */
export function decodeCatalogChunk(raw: {
  meta: Omit<CatalogMeta, "fields"> & { fields: string[] };
  data: unknown[][];
}): CatalogChunk {
  const category = raw.meta.category as CatalogCategory;
  const entries: CatalogEntry[] = raw.data.map((row) => {
    const r = row as RawRow;
    const epochJd = r[FIELD_ORDER.indexOf("epoch_mjd")] * 1 + 2_400_000.5;
    return {
      id: String(r[0]),
      name: String(r[1]),
      category: sbdbClassToCategory(String(r[12]), Boolean(r[13])),
      semiMajorAxisAu: Number(r[2]),
      eccentricity: Number(r[3]),
      inclinationDeg: Number(r[4]),
      longitudeAscNodeDeg: Number(r[5]),
      argPeriapsisDeg: Number(r[6]),
      meanAnomalyDeg: Number(r[7]),
      epochJd,
      periodDays: Number(r[9]),
      diameterKm: r[10] != null ? Number(r[10]) : null,
      absoluteMagnitude: r[11] != null ? Number(r[11]) : null,
      isNEO: Boolean(r[13]),
      isPHA: Boolean(r[14]),
    };
  });
  return { meta: raw.meta as CatalogMeta, entries };
}

void FIELD_ORDER; // suppress unused warning
```

```ts
/**
 * Fetch Solar System catalog snapshots from JPL SBDB Query API.
 *
 * Run with: pnpm solar:fetch-catalog
 * Output:   public/lab/solar-system/catalog/{category}.json + manifest.json
 *
 * Requires internet access to ssd-api.jpl.nasa.gov.
 * Rate limit: 1 request/second as courtesy.
 */

import { writeFileSync, mkdirSync } from "fs";
import { join } from "path";

const OUT_DIR = join(process.cwd(), "public/lab/solar-system/catalog");
const BASE_URL = "https://ssd-api.jpl.nasa.gov/sbdb_query.api";
const FIELDS = "spkid,full_name,a,e,i,om,w,ma,epoch_mjd,per,diameter,H,class,neo,pha";
const TODAY = new Date().toISOString().slice(0, 10);

type FetchJob = {
  filename: string;
  category: string;
  params: Record<string, string>;
  limit?: number;
};

const JOBS: FetchJob[] = [
  {
    filename: "neo.json",
    category: "asteroid-neo",
    params: { "sb-neo": "y", "sb-kind": "a", "sb-group": "neo", "fullname": "true" },
    limit: 40000,
  },
  {
    filename: "mba-top5000.json",
    category: "asteroid-mba",
    params: { "sb-group": "mba", "sb-kind": "a", "sb-cdata.0.crit": "3", "fullname": "true", "sort": "diameter", "dir": "DESC" },
    limit: 5000,
  },
  {
    filename: "comets.json",
    category: "comet",
    params: { "sb-kind": "c", "fullname": "true" },
  },
  {
    filename: "tnos.json",
    category: "tno",
    params: { "sb-group": "tno", "sb-kind": "a", "fullname": "true" },
  },
  {
    filename: "centaurs.json",
    category: "centaur",
    params: { "sb-class": "Cen", "sb-kind": "a", "fullname": "true" },
  },
];

async function fetchChunk(job: FetchJob): Promise<void> {
  const params = new URLSearchParams({
    ...job.params,
    fields: FIELDS,
    ...(job.limit ? { limit: String(job.limit) } : {}),
  });

  const url = `${BASE_URL}?${params}`;
  console.log(`Fetching ${job.filename} ...`);
  console.log(`  URL: ${url}`);

  const res = await fetch(url, {
    headers: { "User-Agent": "Fosforonero-Lab/1.0 (lab.fosforonero.com; contact: hello@fosforonero.com)" },
  });

  if (!res.ok) {
    throw new Error(`SBDB returned ${res.status} for ${job.filename}: ${await res.text()}`);
  }

  const raw = (await res.json()) as { fields: string[]; data: unknown[][] };

  if (!raw.fields || !raw.data) {
    throw new Error(`Unexpected SBDB response shape for ${job.filename}`);
  }

  const out = {
    meta: {
      source: "JPL SBDB Query API",
      url: BASE_URL,
      retrievedAt: TODAY,
      category: job.category,
      count: raw.data.length,
      fields: raw.fields,
    },
    data: raw.data,
  };

  const outPath = join(OUT_DIR, job.filename);
  writeFileSync(outPath, JSON.stringify(out), "utf-8");
  console.log(`  Written ${raw.data.length} entries → ${outPath}`);
}

async function writeManifest(results: Array<{ filename: string; category: string; count: number }>): Promise<void> {
  const manifest = {
    retrievedAt: TODAY,
    source: "JPL SBDB Query API",
    sourceUrl: "https://ssd-api.jpl.nasa.gov/doc/sbdb_query.html",
    chunks: results,
    disclaimer:
      "Orbital elements are from the JPL Small-Body Database. Positions are computed from these elements using Keplerian propagation and are not live JPL Horizons vectors.",
  };
  const outPath = join(OUT_DIR, "manifest.json");
  writeFileSync(outPath, JSON.stringify(manifest, null, 2), "utf-8");
  console.log(`Manifest written → ${outPath}`);
}

async function main() {
  mkdirSync(OUT_DIR, { recursive: true });
  const results: Array<{ filename: string; category: string; count: number }> = [];

  for (const job of JOBS) {
    try {
      await fetchChunk(job);
      // courtesy delay between requests
      await new Promise((r) => setTimeout(r, 1000));
      // read count from written file for manifest
      const written = JSON.parse(
        require("fs").readFileSync(join(OUT_DIR, job.filename), "utf-8")
      ) as { meta: { count: number } };
      results.push({ filename: job.filename, category: job.category, count: written.meta.count });
    } catch (err) {
      console.error(`FAILED: ${job.filename}`, err);
      process.exit(1);
    }
  }

  await writeManifest(results);
  console.log("✅ All catalog chunks fetched successfully.");
}

main();
```

```ts
/**
 * Pure filter functions for CatalogEntry arrays.
 * No side effects. No React dependencies.
 */

import type { CatalogEntry, CatalogCategory } from "./catalog";

export type CatalogFilterOptions = {
  categories?: Set<CatalogCategory>;
  minDiameterKm?: number;
  maxDiameterKm?: number;
  neoOnly?: boolean;
  phaOnly?: boolean;
  maxInclinationDeg?: number;
  maxEccentricity?: number;
  maxSemiMajorAxisAu?: number;
};

export function filterCatalog(
  entries: CatalogEntry[],
  opts: CatalogFilterOptions
): CatalogEntry[] {
  return entries.filter((e) => {
    if (opts.categories && !opts.categories.has(e.category)) return false;
    if (opts.neoOnly && !e.isNEO) return false;
    if (opts.phaOnly && !e.isPHA) return false;
    if (opts.minDiameterKm != null && (e.diameterKm == null || e.diameterKm < opts.minDiameterKm)) return false;
    if (opts.maxDiameterKm != null && e.diameterKm != null && e.diameterKm > opts.maxDiameterKm) return false;
    if (opts.maxInclinationDeg != null && e.inclinationDeg > opts.maxInclinationDeg) return false;
    if (opts.maxEccentricity != null && e.eccentricity > opts.maxEccentricity) return false;
    if (opts.maxSemiMajorAxisAu != null && e.semiMajorAxisAu > opts.maxSemiMajorAxisAu) return false;
    return true;
  });
}

/**
 * Derive a display label for a catalog layer.
 */
export function catalogCategoryLabel(
  cat: CatalogCategory,
```

```ts
import { NextRequest, NextResponse } from "next/server";

const SBDB_SEARCH_URL = "https://ssd-api.jpl.nasa.gov/sbdb.api";
const ALLOWED_CATEGORIES = new Set(["asteroid-neo", "asteroid-mba", "comet", "tno", "centaur", "all"]);

export const runtime = "edge";

export async function GET(req: NextRequest) {
  const { searchParams } = req.nextUrl;
  const q = searchParams.get("q")?.trim();
  const limit = Math.min(Number(searchParams.get("limit") ?? "10"), 20);
  const category = searchParams.get("category") ?? "all";

  if (!q || q.length < 2) {
    return NextResponse.json({ error: "q must be at least 2 characters" }, { status: 400 });
  }

  if (!ALLOWED_CATEGORIES.has(category)) {
    return NextResponse.json({ error: "invalid category" }, { status: 400 });
  }

  // SBDB object lookup by name/designation
  const url = `${SBDB_SEARCH_URL}?sstr=${encodeURIComponent(q)}&mb=-1&moid=1&neo=1&pha=1&nv=1&limit=${limit}&full-prec=0`;

  const res = await fetch(url, {
    next: { revalidate: 3600 },
    headers: {
      "User-Agent": "Fosforonero-Lab/1.0 (lab.fosforonero.com; contact: hello@fosforonero.com)",
    },
  });

  if (!res.ok) {
    return NextResponse.json({ error: `SBDB error: ${res.status}` }, { status: 502 });
  }

  const raw = await res.json() as Record<string, unknown>;

  // SBDB returns either a single object or a list
  type SbdbObject = {
    spkid?: string;
    full_name?: string;
    neo?: string;
    pha?: string;
    class?: string;
    orbit?: {
      elements?: Array<{ name: string; value: string }>;
    };
  };

  const objects: SbdbObject[] = Array.isArray(raw.list)
    ? (raw.list as SbdbObject[])
    : raw.object
    ? [raw as SbdbObject]
    : [];

  const results = objects.slice(0, limit).map((obj) => ({
    id: obj.spkid ?? "",
    name: (obj.full_name ?? "").trim(),
    isNEO: obj.neo === "Y",
    isPHA: obj.pha === "Y",
    sbdbClass: obj.class ?? "",
  }));

  return NextResponse.json({ results, source: "jpl-sbdb", q });
}
```

## Task 5: JPL Horizons On-Demand Vector Route

**Files:**
- Create: `app/api/solar/horizons/route.ts`

Returns the Cartesian state vector for a single body at a given date, cached 1 hour. Used by the inspector when a catalog body is selected.

- [ ] **Step 1: Create `app/api/solar/horizons/route.ts`**

```ts
import { NextRequest, NextResponse } from "next/server";

const HORIZONS_URL = "https://ssd.jpl.nasa.gov/api/horizons.api";

export const runtime = "edge";

export async function GET(req: NextRequest) {
  const { searchParams } = req.nextUrl;
  const id = searchParams.get("id");
  const date = searchParams.get("date"); // ISO date, e.g. "2026-05-31"

  if (!id || !date) {
    return NextResponse.json({ error: "id and date are required" }, { status: 400 });
  }

  // Validate date format
  if (!/^\d{4}-\d{2}-\d{2}$/.test(date)) {
    return NextResponse.json({ error: "date must be YYYY-MM-DD" }, { status: 400 });
  }

  const stopDate = new Date(date);
  stopDate.setDate(stopDate.getDate() + 1);
  const stopStr = stopDate.toISOString().slice(0, 10);

  const params = new URLSearchParams({
    format: "json",
    COMMAND: `'${id}'`,
    OBJ_DATA: "NO",
    MAKE_EPHEM: "YES",
    EPHEM_TYPE: "VECTORS",
    CENTER: "500@10",   // Sun-centred
    START_TIME: date,
    STOP_TIME: stopStr,
    STEP_SIZE: "1d",
    OUT_UNITS: "KM-S",
    VEC_TABLE: "2",    // XYZ + VX VY VZ
    REF_PLANE: "ECLIP",
    REF_SYSTEM: "J2000",
  });

  const url = `${HORIZONS_URL}?${params}`;

  const res = await fetch(url, {
    next: { revalidate: 3600 },
    headers: {
      "User-Agent": "Fosforonero-Lab/1.0 (lab.fosforonero.com; contact: hello@fosforonero.com)",
    },
  });

  if (!res.ok) {
    return NextResponse.json({ error: `Horizons error: ${res.status}` }, { status: 502 });
  }

  const raw = await res.json() as { result?: string; error?: string };

  if (raw.error) {
    return NextResponse.json({ error: raw.error }, { status: 422 });
  }

  const text = raw.result ?? "";

  // Parse Horizons vector output — format: $$SOE ... X = ... Y = ... Z = ... $$EOE
  const soeIdx = text.indexOf("$$SOE");
  const eoeIdx = text.indexOf("$$EOE");
  if (soeIdx === -1 || eoeIdx === -1) {
    return NextResponse.json({ error: "Could not parse Horizons output" }, { status: 502 });
  }

  const block = text.slice(soeIdx + 5, eoeIdx);

  function parseVal(label: string): number {
    const re = new RegExp(`${label}\\s*=\\s*([\\-\\+]?[0-9.E+\\-]+)`);
    const m = re.exec(block);
    return m ? parseFloat(m[1]) : 0;
  }

  const positionKm: [number, number, number] = [
    parseVal("X"),
    parseVal("Y"),
    parseVal("Z"),
  ];
  const velocityKmS: [number, number, number] = [
    parseVal("VX"),
    parseVal("VY"),
    parseVal("VZ"),
  ];

  return NextResponse.json({
    id,
    date,
    positionKm,
    velocityKmS,
    source: "jpl-horizons",
    epochIso: `${date}T00:00:00Z`,
    cachedAt: new Date().toISOString(),
  });
}
```

## Task 6: CatalogLayer Three.js Component

**Files:**
- Create: `components/lab/solar-system-catalog-layer.tsx`

This is the core rendering task. Uses `THREE.Points` with a `BufferGeometry` to render thousands of catalog objects as coloured points without individual React meshes. Positions are computed from SBDB orbital elements using the Sprint 02 Keplerian solver.

- [ ] **Step 1: Create `components/lab/solar-system-catalog-layer.tsx`**

```tsx
"use client";

import { useMemo, useRef } from "react";
import { useFrame } from "@react-three/fiber";
import * as THREE from "three";
import type { CatalogEntry, CatalogCategory } from "@/lib/solar-system/catalog";
import type { ScaleDistanceMode } from "@/lib/solar-system/bodies";
import { scaleDistance, AU_KM } from "@/lib/solar-system/scales";

// ---------------------------------------------------------------------------
// Category colours
// ---------------------------------------------------------------------------

const CATEGORY_COLOR: Record<CatalogCategory, THREE.Color> = {
  "asteroid-neo": new THREE.Color("#ff6b35"),
  "asteroid-mba": new THREE.Color("#8a9ba8"),
  "asteroid-other": new THREE.Color("#6b7c8a"),
  comet: new THREE.Color("#a8d8f0"),
  tno: new THREE.Color("#c8a8d8"),
  centaur: new THREE.Color("#d8c8a8"),
};

// ---------------------------------------------------------------------------
// J2000 constants (duplicated from ephemeris to avoid importing server module)
// ---------------------------------------------------------------------------

const J2000_JD = 2_451_545.0;
const UNIX_EPOCH_JD = 2_440_587.5;
const TWO_PI = 2 * Math.PI;

function solveKepler(M: number, e: number): number {
  const Mn = ((M % TWO_PI) + TWO_PI) % TWO_PI;
  let E = e > 0.8 ? Math.PI : Mn;
  for (let i = 0; i < 20; i++) {
    const dE = (E - e * Math.sin(E) - Mn) / (1 - e * Math.cos(E));
    E -= dE;
    if (Math.abs(dE) < 1e-8) break;
  }
  return E;
}

function keplerToXyzAu(
  aAu: number,
  e: number,
  iDeg: number,
  OmegaDeg: number,
  omegaDeg: number,
  M: number
): [number, number, number] {
  const E = solveKepler(M, e);
  const cosE = Math.cos(E);
  const sinE = Math.sin(E);
  const oneMecosE = 1 - e * cosE;
  const r = aAu * oneMecosE;
  const cosNu = (cosE - e) / oneMecosE;
  const sinNu = (Math.sqrt(Math.max(0, 1 - e * e)) * sinE) / oneMecosE;
  const nu = Math.atan2(sinNu, cosNu);
  const opn = (omegaDeg * Math.PI) / 180 + nu;
  const iR = (iDeg * Math.PI) / 180;
  const OR = (OmegaDeg * Math.PI) / 180;
  const cO = Math.cos(OR), sO = Math.sin(OR);
  const cI = Math.cos(iR), sI = Math.sin(iR);
  const cN = Math.cos(opn), sN = Math.sin(opn);
  return [
    r * (cO * cN - sO * sN * cI),
    r * (sO * cN + cO * sN * cI),
    r * sN * sI,
  ];
}

// ---------------------------------------------------------------------------
// Component
// ---------------------------------------------------------------------------

export type CatalogLayerProps = {
  entries: CatalogEntry[];
  category: CatalogCategory;
  epoch: Date;
  distanceMode: ScaleDistanceMode;
  visible: boolean;
  onSelectEntry?: (entry: CatalogEntry) => void;
};

export function CatalogLayer({
  entries,
  category,
  epoch,
  distanceMode,
  visible,
}: CatalogLayerProps) {
  const pointsRef = useRef<THREE.Points>(null);

  const color = CATEGORY_COLOR[category] ?? new THREE.Color(1, 1, 1);

  const { positions, count } = useMemo(() => {
    const jd = epoch.getTime() / 86_400_000 + UNIX_EPOCH_JD;
    const buf = new Float32Array(entries.length * 3);
    let n = 0;

    for (const e of entries) {
      // skip hyperbolic/parabolic orbits
      if (e.eccentricity >= 1.0 || e.semiMajorAxisAu <= 0) continue;

      const daysSinceEpoch = jd - e.epochJd;
      const M0 = (e.meanAnomalyDeg * Math.PI) / 180;
      const meanMotion = TWO_PI / e.periodDays;
      const M = ((M0 + meanMotion * daysSinceEpoch) % TWO_PI + TWO_PI) % TWO_PI;

      const [xAu, yAu, zAu] = keplerToXyzAu(
        e.semiMajorAxisAu,
        e.eccentricity,
        e.inclinationDeg,
        e.longitudeAscNodeDeg,
        e.argPeriapsisDeg,
        M
      );

      const xKm = xAu * AU_KM;
      const yKm = yAu * AU_KM;
      const zKm = zAu * AU_KM;

      let sx: number, sy: number, sz: number;
      if (distanceMode === "compressed") {
        sx = xAu; sy = yAu; sz = zAu;
      } else {
        const magKm = Math.sqrt(xKm * xKm + yKm * yKm + zKm * zKm);
        if (magKm < 1) { buf[n * 3] = 0; buf[n * 3 + 1] = 0; buf[n * 3 + 2] = 0; n++; continue; }
        const f = scaleDistance(magKm, distanceMode) / magKm;
        sx = (xKm * f) / AU_KM; sy = (yKm * f) / AU_KM; sz = (zKm * f) / AU_KM;
        // Note: for non-compressed modes positions are in render-unit scale, not AU
        // Recompute correctly:
        const renderMag = scaleDistance(magKm, distanceMode);
        const scale = renderMag / magKm;
        buf[n * 3]     = xKm * scale;
        buf[n * 3 + 1] = yKm * scale;
        buf[n * 3 + 2] = zKm * scale;
        n++;
        continue;
      }
      buf[n * 3]     = sx;
      buf[n * 3 + 1] = sy;
      buf[n * 3 + 2] = sz;
      n++;
    }

    return { positions: buf.slice(0, n * 3), count: n };
  }, [entries, epoch, distanceMode]);

  const geometry = useMemo(() => {
    const geo = new THREE.BufferGeometry();
    geo.setAttribute("position", new THREE.BufferAttribute(positions, 3));
    return geo;
  }, [positions]);

  // No animation needed — positions update via useMemo when epoch changes

  if (!visible || count === 0) return null;

  return (
    <points ref={pointsRef} geometry={geometry}>
      <pointsMaterial
        color={color}
        size={0.025}
        sizeAttenuation
        transparent
        opacity={0.7}
        depthWrite={false}
      />
    </points>
  );
}

void J2000_JD; // suppress unused
```

```ts
import { readFileSync, existsSync } from "fs";
import { join } from "path";

const CATALOG_DIR = join(process.cwd(), "public/lab/solar-system/catalog");
const REQUIRED_CHUNKS = ["neo.json", "mba-top5000.json", "comets.json", "tnos.json", "centaurs.json", "manifest.json"];

console.log("\n--- Catalog snapshot checks ---");
let catalogWarnings = 0;

for (const file of REQUIRED_CHUNKS) {
  const path = join(CATALOG_DIR, file);
  if (!existsSync(path)) {
    console.log(`  [WARN] Missing catalog chunk: ${file} — run pnpm solar:fetch-catalog`);
    catalogWarnings++;
  } else {
    const size = (readFileSync(path).length / 1024).toFixed(0);
    const meta = JSON.parse(readFileSync(path, "utf-8"));
    const count = meta.meta?.count ?? meta.chunks?.length ?? "?";
    console.log(`    OK  ${file.padEnd(24)} ${size.padStart(6)} kB  count=${count}`);
  }
}

warnings += catalogWarnings;
```

## Risk Notes

**SBDB API changes:** The SBDB Query API is a public NASA API. Field names and parameter names are documented but may change. The fetch script should be re-run periodically and the output validated by the audit. The retrieval date in `manifest.json` makes staleness visible.

**Catalog file sizes:** `neo.json` may reach 5–10 MB. Consider adding a `.gitattributes` LFS entry if the repo grows too large. For Sprint 03, commit the files directly.

**Keplerian accuracy for catalog objects:** SBDB orbital elements are accurate at their reference epoch but diverge for highly perturbed bodies (NEOs near planetary encounters, high-eccentricity comets). The data quality label in the inspector must always show "catalog-keplerian" for these bodies, never "sub-km".

**CatalogLayer position recompute:** Computing positions for 35 000 NEOs every epoch change would be slow. Implement lazy recompute: only recompute when the layer is visible AND the epoch has changed by more than 1 day. Use a `prevEpoch` ref to gate updates.
